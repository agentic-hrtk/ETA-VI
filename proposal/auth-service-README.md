# OAuth2 / JWT Authentication Microservice

This microservice provides OAuth2 and JWT authentication for the application.

## Features
- User registration and login
- Token generation and validation
- Role-based access control

## Configuration
- `AUTH_SERVICE_SECRET`: Secret key for JWT token signing (REDACTED)
- `DATABASE_URL`: URL for the database connection (REDACTED)

## Usage
To use this service, you need to set the environment variables and run the application.
